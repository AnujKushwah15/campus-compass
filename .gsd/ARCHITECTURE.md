## Overview

Campus Compass is a unified web application and backend service designed for real-time tracking, live streaming, and management of a bus fleet. The system employs a Next.js frontend for various user roles (Admin, Driver, Parent, Student) and a Node.js/Express backend that handles location arbitration from multiple hardware sources (GPS, IMU, Phone) and manages secure video streaming through MediaMTX.

## Data Flow

1. **Location Tracking:** Raspberry Pi (with GPS/IMU) and Driver Phone push location data to Firebase RTDB.
2. **Arbitration:** The backend watches RTDB `buses/{busId}/sources`, selects the best signal (Pi vs. Phone) using timestamps and quality indicators, and updates `active_source` and `location`.
3. **Stream Authentication:** Frontend requests a stream token via `/api/stream-token`. The backend verifies the user's Firebase token, checks role-based access rules, and returns a JWT.
4. **Video Streaming:** MediaMTX serves the stream and checks read permission via the `/stream-auth` webhook on the backend, ensuring only authorized users view the feed.
